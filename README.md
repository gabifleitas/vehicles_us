# vehicles_us

This project consists of building and deploying an interactive web application with Streamlit, connected to an exploratory data analysis of used car advertisements in the United States. The app allows data to be visualised using dynamic graphics and was developed as part of technical training in development tools.

This is part of the Tripleten bootcamp.
We are analyzing a vehicle's database.

Here is the link: https://vehicles-us-huc3.onrender.com

# vehicles_us

Este proyecto consiste en crear e implementar una aplicación web interactiva con Streamlit, conectada a un análisis exploratorio de datos de anuncios de coches usados en Estados Unidos. La aplicación permite visualizar los datos mediante gráficos dinámicos y se ha desarrollado como parte de la formación técnica en herramientas de desarrollo.

Esto forma parte del bootcamp Tripleten.
Estamos analizando la base de datos de un vehículo.

Aquí está el enlace: https://vehicles-us-huc3.onrender.com
